ย้ายและสำรองข้อมูล

ระบบงบประมาณ 2570 / แผนเงินบำรุง / UC ข้อมูลแก้ไขในเว็บเดิมเก็บอยู่ในเบราว์เซอร์ ไม่ถูกย้ายตาม URL โดยอัตโนมัติ

1. สำรองข้อมูลที่อยู่ในเว็บนี้

กดก่อนนำเข้าข้อมูล เพื่อรักษาของเดิมไว้เป็นไฟล์ JSON

2. นำเข้าข้อมูลจากเว็บ AppDeploy เดิม

เลือกไฟล์ JSON ที่ส่งออกจากเว็บเก่า (ดูวิธีใน README ของโครงการ) ข้อมูลจะนำเข้าเฉพาะเบราว์เซอร์นี้เท่านั้น

กลับระบบ UC

คำเตือน: ไฟล์แนบใบสั่งซื้ออยู่ใน Storage ของ AppDeploy แยกจากรายการข้อมูล ต้องย้ายไฟล์แนบต่างหากก่อนปิดเว็บเดิม
