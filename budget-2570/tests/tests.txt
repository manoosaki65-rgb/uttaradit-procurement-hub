# Tests

## Test 1 - ตรวจข้อมูลจริง UC และค้นหารายการ [sanity]
Viewport: desktop
Covers: UC actual source data, full-text search, procurement officer column, pagination, module-only desktop layout and homepage return link
Description: ตรวจสอบว่าหน้า UC มีข้อมูลจริงและค้นหารายการหรือเจ้าหน้าที่ได้

Steps:
1. เปิดแอปด้วย URL ที่ลงท้าย #uc โดยตรง แล้วค้นหา “อุปกรณ์ประคองศีรษะและคอ”
2. ตรวจ Inventory และเจ้าหน้าที่จัดซื้อ
3. เปิดรายละเอียดรายการ

Expected: พบรายการพร้อม Inventory 69-02875 เจ้าหน้าที่ “นัชชา” และรายละเอียดเปิดได้ หน้า UC ไม่มีแถบเมนูรวมด้านข้าง และมีปุ่มกลับหน้าโฮมเพจ

## Test 2 - แสดงขั้นปัจจุบันเพียงจุดเดียวและแนบใบสั่งซื้อ
Viewport: desktop
Covers: current-stage highlight, purchase-order storage upload/download, procurement fields, GET/POST order-file API
Description: ตรวจสอบว่าขั้นปัจจุบันเด่นเพียงวงกลมเดียวและสามารถแนบ/ดาวน์โหลดใบสั่งซื้อหรือสั่งจ้างได้

Steps:
1. ค้นหา “เครื่องพยุงการทำงานของหัวใจและหลอดเลือด” และตรวจวงกลมสถานะ
2. เปิดรายการและแนบไฟล์เอกสารขนาดเล็กในช่อง “ใบสั่งซื้อ / ใบสั่งจ้าง”
3. เปิดรายการเดิมอีกครั้งและกดดาวน์โหลดไฟล์ที่แนบ

Expected: เฉพาะวงกลมเลข 4 มีสีเด่น ส่วน 1, 2, 3, 5 เป็นสีเทา และมีปุ่มดาวน์โหลดไฟล์ที่แนบไว้

## Test 3 - แก้ไขเจ้าหน้าที่จัดซื้อและเก็บข้อมูลหลังรีเฟรช

Covers: modal editing, procurement officer input, local persistence, search by officer

Expected: พบรายการเดิมจากชื่อเจ้าหน้าที่ที่กรอกและข้อมูลยังอยู่หลังรีเฟรช

## Test 4 - กรอกเลขรับ Inventory จากสถานะรายการแผนเงินบำรุงบนมือถือ
Viewport: mobile
Covers: maintenance-plan category tabs, unit filter, Inventory receipt filter, editable Inventory number and received date, persistence after refresh, single fixed-height scrollable table viewport with immediately accessible horizontal scrollbar
Description: ตรวจสอบว่ารายการที่ยังไม่ได้รับสามารถเปิดกรอกเลขรับ Inventory และวันที่รับ แล้วบันทึกสถานะรับได้

Steps:
1. เปิดแอปด้วย URL ที่ลงท้าย #plan โดยตรง กดปี 2569 เลือกหมวดที่มีรายการ และกรอง “ยังไม่ได้รับ”
2. กดสถานะ “ยังไม่ได้รับ” ของรายการหนึ่ง กรอกเลขรับ Inventory “69-TEST” และวันที่รับ “13 ก.ย. 69” แล้วบันทึก
3. เปลี่ยนตัวกรองเป็น “รับแล้ว” และรีเฟรชหน้า

Expected: รายการที่แก้แสดงเลข “69-TEST” วันที่ “13 ก.ย. 69” และสถานะ “รับแล้ว” และข้อมูลยังอยู่หลังรีเฟรช

## Test 6 - เข้าโมดูลโดยตรงโดยไม่มีเมนูรวมบนมือถือ
Viewport: mobile (375x667)
Covers: direct module links #budget/#uc/#plan, module-only full-width layout, homepage return link, refresh and invalid module fallback
Description: ทดสอบทางเข้าจาก Homepage โดยอ่านข้อมูลเดิมเท่านั้น ไม่กรอก บันทึก ลบ หรืออัปโหลดข้อมูลทดสอบ

Steps:
1. เปิด URL ของแอปที่ลงท้าย #budget โดยตรง ตรวจหน้ารายการเงินงบประมาณและปุ่มกลับหน้าโฮมเพจ แล้วรีเฟรช
2. เปิด URL ที่ลงท้าย #uc โดยตรง ค้นหาอุปกรณ์ประคองศีรษะและคอ ตรวจ Inventory 69-02875 และเปิดรายละเอียดแล้วปิดโดยไม่บันทึก
3. เปิด URL ที่ลงท้าย #plan โดยตรง กดปี 2569 แล้วเลือกหมวดครุภัณฑ์การแพทย์ต่ำแสน ตรวจว่าตารางและตัวกรองยังใช้งานได้
4. ตรวจทั้งสามหน้าว่าไม่มีแถบด้านข้าง ตราตัว พ หรือไอคอนเมนูของระบบอื่น ตรวจว่าปุ่มกลับหน้าโฮมเพจชี้ไป https://uttaradit-procurement-hub.manoosaki65.chatgpt.site และพื้นที่เนื้อหาเริ่มจากขอบหน้าตามระยะ padding โดยไม่มีช่องว่าง sidebar
5. รีเฟรช #plan ตรวจว่ายังเป็นแผนเงินบำรุง จากนั้นเปิด #unknown ตรวจว่าเปิดหน้า UC เดิมได้โดยไม่มีหน้าว่าง

Expected: แต่ละ URL เปิดเฉพาะโมดูลตรงชื่อ เนื้อหาใช้พื้นที่เต็มกว้าง ไม่มีเมนูรวมซ้ำ ปุ่มกลับหน้าโฮมเพจเห็นและเข้าถึงได้ ข้อมูล UC เดิมและหน้าแผนปี 2569 ยังเปิดได้ รีเฟรชคงโมดูลที่เลือก และ hash ที่ไม่รองรับกลับไป UC อย่างปลอดภัย

## Test 7 - งบประมาณปี 2570 แสดงข้อมูลรับล่าสุดและงบต่อเนื่อง
Viewport: desktop
Covers: 2570 budget latest Inventory data, continuing-budget status, true pending items
Description: ตรวจสอบข้อมูลล่าสุดของงบประมาณปี 2570 โดยไม่ทำให้รายการก่อสร้างถูกนับเป็นรายการค้างส่ง

Steps:
1. เปิด URL ที่ลงท้าย #budget และค้นหาเลข 69-05298 จากนั้นตรวจวันที่รับ
2. ค้นหาเลข 69-05362 และ 69-05364 และตรวจว่าพบรายการพร้อมวันที่รับ 17/09/69
3. ค้นหาเลข 69-05132 และตรวจรายการ “เตียงผ่าตัดทั่วไประบบไฟฟ้า พร้อมรีโมทคอนโทรล” ว่าวงเงินอนุมัติ 3,484,800 บาท วันที่รับ 04/09/69 และสถานะ “รับ Inventory แล้ว”
4. ค้นหา “อาคารระบบบำบัดน้ำเสีย” และ “อาคารศูนย์สุขภาพชุมชนเมือง” แล้วตรวจสถานะ

Expected: พบ Inventory 69-05298, 69-05362, 69-05364 และ 69-05132 พร้อมวันที่รับที่ถูกต้อง; รายการ 69-05132 แสดงวงเงินอนุมัติ 3,484,800 บาทและสถานะ “รับ Inventory แล้ว”; รายการก่อสร้างทั้งสองแสดงสถานะ “งบประมาณต่อเนื่อง” ไม่ใช่ “ยังไม่เริ่ม”

## Test 8 - รีเฟรชหน้าเว็บแล้วใช้ข้อมูล Master ล่าสุดแทน cache เก่า

Covers: 2570 master-data precedence, stale local cache migration, mobile budget table

Steps:
